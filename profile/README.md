## DESCIPHR-GC

Stanford's gastric cancer simulation model for the NCI Cancer Intervention and Surveillance Modeling
Network (CISNET), built on the DESCIPHR framework for discrete-event simulation of cancer natural
history and control interventions in R.

| Repository | What it holds |
|---|---|
| `desciphrgc` | R package: natural history of non-cardia gastric adenocarcinoma and interventions (H. pylori test-and-treat, endoscopic screening, endoscopic therapy, surveillance) |
| `cal_val_desciphrgc` | Calibration (BayCANN) and validation of the model |

Model documentation follows the CISNET model profile structure. The framework is described in
Pi et al., PharmacoEconomics 2026;44:409-427 (doi:10.1007/s40273-025-01571-3).
